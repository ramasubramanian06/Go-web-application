MY PROJECT 01

Project Description: Dockerized website deployment

Designed and deployed a Go-based web application by implementing an end-to-end DevOps workflow. Containerized the application using Docker to ensure consistent development and deployment environments and published versioned Docker images to a container registry. Deployed and managed the containerized application on Kubernetes and used Helm charts to package, configure, and manage Kubernetes resources across deployments. Implemented Continuous Integration using GitHub Actions to automate Go application builds, unit testing, static code analysis, Docker image creation, and image publishing. Implemented GitOps-based Continuous Deployment using Argo CD to automatically synchronize Kubernetes manifests from GitHub and deploy application updates to the Kubernetes cluster.
